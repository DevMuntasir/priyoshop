Circular, icon-only button for carousel arrows and play controls.

```jsx
<IconButton ariaLabel="Next" variant="outline"><Icon name="arrow-right" /></IconButton>
<IconButton tone="brand" variant="filled"><PlayIcon variant="filled" /></IconButton>
```

Variants `filled · outline · ghost`, tones `dark · light · brand`, sizes `sm 36 · md 44 · lg 56`.
