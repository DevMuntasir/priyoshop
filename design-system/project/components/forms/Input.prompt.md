Rounded text input (16px radius) with a red focus ring, optional label, leading icon, and hint/error text.

```jsx
<Input label="Email" placeholder="you@example.com" type="email" />
<Input placeholder="Search products" iconLeft={<Icon name="search" size={20} />} />
<Input label="Phone" error="Enter a valid number" />
```

Sizes `sm · md · lg`. Set `disabled` for the muted state.
