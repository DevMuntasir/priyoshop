Capsule label in Open Sans SemiBold. The `outline` variant is PriyoShop's signature section eyebrow that floats above big Lato titles.

```jsx
<Badge>Ecosystem at a Glance</Badge>
<Badge tone="brand" variant="soft">New</Badge>
<Badge tone="gold" variant="solid">Featured</Badge>
```

Variants `outline · soft · solid`, tones `ink · brand · gold`, sizes `sm · md`.
