Thin line icons that inherit `color`. Brand arrows are pulled 1:1 from Figma; the rest follow the same single-weight line style. `PlayIcon` is the play glyph for video CTAs.

```jsx
<Icon name="arrow-right" />
<Icon name="search" size={20} />
<PlayIcon variant="outline" />
```

For a fuller UI icon set, load Lucide from CDN — it matches this line weight.
